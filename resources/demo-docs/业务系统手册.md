# 业务系统手册

> 本文档用于 SageRAG 演示，介绍公司内部 OA、审批、公告与文档中心的使用方式。

## 一、OA 系统概览

OA 系统是公司统一的办公入口，主要提供以下能力：

- 流程审批：请假、报销、采购、用印、合同、出差等流程。
- 待办中心：集中查看待我审批、我发起的、抄送我的流程。
- 公告通知：公司级公告、部门公告、制度更新。
- 文档中心：制度文件、模板、会议纪要的在线预览与下载。
- 日程与会议室：会议室预订、日程共享。

## 二、发起审批

1. 登录 OA，进入「流程中心」→「发起流程」。
2. 选择流程类型，例如「请假申请」「差旅报销」「采购申请」。
3. 填写表单并上传附件，系统会根据金额、天数自动匹配审批链路。
4. 提交后可在「我发起的」查看进度，审批人可在「待我审批」处理。

## 三、请假审批在哪个菜单

请假审批入口：OA → 流程中心 → 人事流程 → 请假申请。
审批人处理入口：OA → 待办中心 → 待我审批。

## 四、公告与文档

1. 公告发布后会在首页弹出提醒，重要公告需阅读确认。
2. 文档中心按部门目录归档，支持按标题、标签、更新时间检索。
3. 制度文件以文档中心版本为准，聊天助手回答仅作辅助。

## 五、常见问题

- 忘记 OA 密码：在登录页点击「忘记密码」，通过邮箱验证重置；仍失败请联系 IT 服务台。
- 审批人请假：可在流程中点击「转交」，转交给同部门负责人。
- 流程被退回：根据退回意见修改后重新提交，无需新建流程。
- 移动端使用：OA 支持企业微信/钉钉工作台入口，功能与网页端一致。
